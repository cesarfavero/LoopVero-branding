# LoopVero brand guide

## Identity

Use **LoopVero** with exactly this capitalization. The draft symbol is a broken rounded loop with a small terminal square: a simple geometric suggestion of a run and a visible result. It is an original SVG drawing for this package, not a claim of trademark exclusivity.

Primary tagline: **Don’t just show the answer. Show the work.**

Portuguese tagline: **Não mostre só a resposta. Mostre o trabalho.**

## Assets

- `mark.svg`: square symbol, dark background, mint foreground.
- `wordmark.svg`: symbol and text lockup for a dark background.
- `tokens.css`: CSS color, spacing, radius, and font-stack tokens.

Use the symbol with at least one terminal-square width of clear space. Do not use it as a certification or verification badge. Keep status text separate and visible when presenting a planned feature or a concept mockup.

## Color and typography

Ink `#101820`, paper `#F4F7F9`, mint `#6FF0C4`, muted `#A9B8C5`. Use mint on ink, and ink on paper. Do not assume every combination meets accessibility requirements. Use a system sans-serif stack; no font files are bundled. Wordmark rendering may vary with installed fonts.

## Voice

Direct, specific, and calm. Say what happened and what was checked. Prefer “planned” to “coming soon” when no date is committed. Avoid unsupported claims such as “tamper-proof,” “production-ready,” “secure by default,” “fully autonomous,” or “guaranteed correct.”
